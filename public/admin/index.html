Gestão de conteúdos da ARLA

Esta página carrega o Decap CMS, o editor de conteúdos do sítio. Se está a ver esta mensagem, o editor ainda não arrancou. As causas possíveis, por ordem de probabilidade:

  • Não há ligação à Internet (o editor é descarregado de unpkg.com).
  • A autenticação OAuth do GitHub ainda não está configurada em produção — ver docs/implantacao.md.
  • A branch indicada em /admin/config.yml não existe no repositório. Está por decidir qual é a branch publicada.
  • O ficheiro do editor não corresponde ao integrity declarado nesta página e o navegador recusou-o. Veja a consola do navegador.

Instruções completas em docs/gestao-de-conteudos.md e docs/implantacao.md, no repositório.
